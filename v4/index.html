01装载场景

枚举全部姿态与码放策略，取装载率最高方案。

每种箱型的运费、单次成本、角件都在「温控箱模板」里维护；这里只决定"允许用哪几种"。

02温控箱模板（被动式）
内径是怎么算出来的（推导口径 + 装载率分母）
长 / 宽外径 − 2×(侧壁保温层 + 四壁冷板)
高外径 − 顶部冷板仓 − 底部托盘+冷板
可用装载区内径 − 四侧冷气通道 − 顶部余量

高方向不再扣一次「保温层×2」：顶部与底部的保温已经含在「顶部冷板仓」「底部托盘+冷板」这两个实体厚度里，再扣就是重复扣减。

四壁不贴蓄冷板就把冷板厚度填 0（托盘级常规做法）；贴板时每侧都占厚度，可用宽度会明显缩小。拿到实测内腔后切「直接输入内径」，推导值立即失效、以手输值为准。

装载率有两个分母：KPI 上那个用内径体积（含着四侧冷气通道），所以永远上不到 100%；报告里另给一个可用区体积口径，只算算法真正能支配的空间，同一批货会高出几个点到十几个点。跟客户或审计对数前，先确认用的是哪个口径。

启用内衬后还要再扣一层内衬壁厚：内衬外形 = 内腔 + 2×壁厚，产品可用空间比这里算出来的更小。

03内衬箱（可选）

内腔三个框填 0 = 自动比选最优内腔；填了数字就按你给的内腔算。

04产品清单 + 添加产品

姿态开关是全局合规约束（医药液体类通常仅允许正放）。

05码放策略

参数改动后需重新点「计算最优方案」；改颜色不用重算。
