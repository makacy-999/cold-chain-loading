# v4 · 温控箱装载方案系统（v1.12.4 在线版）

打开 `index.html` 即是完整可用的装载系统（单文件自包含，零外部依赖，可离线双击运行）。

- 在线访问：<https://makacy-999.github.io/cold-chain-loading/v4/>
- 本版要点（**悬空清零**）
  - 装载算法从「全局分层」改成**按列码垛**：地面铺一层，每块底座是一根柱子的底面，
    每根柱子往上摞同款箱子。上层底面与下层完全对齐，每一件都整片坐在下一件顶面上，
    **悬空在构造上不可能出现**，也不再受「尺寸是否为 10 的整数倍」影响。
  - 为什么必须重做：前两版每层各自平铺、层间没有坐标约束，层高又允许装矮货，
    矮货顶上留空、再往上排的那件就整片吊在半空。随机 20 组纯软货 1528 件里 88 件悬空
    （最差踩实率 20%），含不可压货 40 组 2558 件里 111 件悬空（最差 30%）。
    也试过 10mm 栅格掩码逐层压茬，但非 10 整数倍的尺寸（如 143×103）最后一格永远盖不满，
    上一层一件都放不下去、件数从 1528 掉到 453，这条路对任意尺寸不成立。
  - 配套：地面按需求量配额分配（大件先占、小件扫尾填缝）、地面整体居中（防偏载）、
    不可压货坐柱顶（柱子削到「箱高 − 硬货高」，上方不再放货）、候选去重。
  - 实测：纯软货 1528 → 1529 件、体积利用率 46.5% → 46.6%、悬空 88 → **0**；
    含不可压 40 组 2578 件**零悬空、最差踩实率 100%**。一物一箱 634 → 630 件
    （那 4 件本来就是靠错缝塞出来的，错缝处就是悬空）。
